# OpenNano 设计语言（单一规则来源）

> 2026-09-13 建立（工具线）。起因是owner一句：「**总之你来统一设计语言，不要每个分区都是自己一套规则**」。
> 规矩只有一条：**任何尺寸/颜色/圆角都从下面的 token 取**，组件里不许再写裸值。违反会被 `工具/设计语言体检.py` 扫出来。

## 1. token 在哪

`web/src/styles.css` 的 `:root` 顶部：字号 6 档 · 间距 5 档 · 圆角 3 档 · 字距 2 档 · 颜色全套（含三主题覆盖）。

| 类别 | token | 值 | 用在哪 |
|---|---|---|---|
| 字号 | `--fs-micro` | 10.5px | 全大写微标签：表头、区块帽 |
| | `--fs-xs` | 11px | 辅助：状态栏、脚注、时间戳 |
| | `--fs-sm` | 11.5px | 次要正文：表体数字、卡片说明 |
| | `--fs-base` | 12px | 界面正文：按钮、下拉、表单标签 |
| | `--fs-md` | 12.5px | 强调正文：卡片标题、节点副标题 |
| | `--fs-lg` | 13.5px | 标题：节点名、面板标题、品牌字标 |
| 间距 | `--sp-1…--sp-5` | 4 / 6 / 8 / 12 / 16px | 内边距、行距、栅格缝 |
| 圆角 | `--r-sm/md/lg` | 6 / 8 / 12px | 芯片 / 卡片 / 面板（`--radius*` 只是别名） |
| 字距 | `--track-latin` | .05em | 拉丁小标签（全大写那种） |
| | `--track-cjk` | .01em | **中文标签**（中文加宽会很散，别用拉丁那套） |
| 颜色 | `--bg/--panel/--surface/--raise/--hover` | 5 级灰阶 | 表面分层（60/30/10 里的 60+30） |
| | `--text/--text-2/--muted/--faint` | 4 级文字 | 标题→正文→辅助→禁用，对比度全 ≥4.5:1 |
| | `--accent` / `-hi` / `-lo` / `-text` | 靛紫四态 | **默认/悬浮/激活/文字专用档**（文字不许用 `--accent`） |
| | `--ok/--warn/--bad` | 语义三色 | 只表状态，不做品牌表达 |
| | `--fam-*` | 15 个工艺族色 | **数据编码**（同 Linear 的 label 色板），只做小面积 |

## 2. 六条硬规矩

1. **字号不许裸写**：CSS 用 `var(--fs-*)`，TSX 用 `fontSize: 'var(--fs-*)'`。（原来 CSS 13 种、TSX 92 处内联，就是"每个分区一套规则"的来源。）
2. **颜色不许裸写**：不许出现 `#hex`／`rgba()` 字面量（数据编码用的族色、以及 `color-mix` 之类的合成除外）。
3. **中文标签不加宽字距**：中文用 `--track-cjk`；`text-transform: uppercase` 只对拉丁标签用。
4. **强调色唯一且克制**：全局只有靛紫一个强调色相；它只出现在 Logo / 主按钮 / 链接 / 选中态 / 关键数据；**文字档必须用 `--accent-text`**（`--accent` 当文字对比度 4.08 < 4.5）。
5. **彩色只做小面积**：族色只出现在"2–3px 色条 / 6–7px 圆点 / 5px 方块 / 描边 / 极淡底染（≤7%）"；大面积一律灰阶。
6. **三主题同源**：`linear`（默认深色）/ `light` / `hc` 三套只覆盖 token，不改组件规则。改主题=改 token 值。

## 3. 组件与层级

- 表面从深到浅：`bg`（画布）→ `panel`（左右栏/顶栏/底栏）→ `surface`（卡片）→ `raise`（芯片底）→ `hover`。
- 层级 z-index：`main 1 → 噪点 2 → 状态栏 3 → dock 110 → topbar 120 → 浮层 2000 → 右键菜单 2500`。
  ⚠️ 教训：`backdrop-filter` 会自建层叠上下文，外壳必须显式配 z-index，否则内部菜单被后面的兄弟盖住。
- 可点击元素一律 `white-space: nowrap` + `flex-shrink: 0`（不许被压成一字一行）。
- **布局尺寸的唯一来源在 `server/kb/canvas_geom.py`**（节点宽/高、GAP、列距、错位量）——前端不许另写一套。

## 4. 语言（**全英文**）

**2026-09-13 定案：界面文案只有英文一份**（`web/src/i18n/en.ts`），语言开关已撤 → `docs/i18n.md`。
**术语与 id 一律保持原样**（`run_id` / `stage_seq` / `core` / 工序名 / 参数键 / 单位 / 状态枚举值），
所以界面上出现 `PECVD`、`cd_delta_nm`、`胶CD`、`AR50-T1-明天` 是**故意的**（翻了对不上库）。
中文标签的排版规矩（`--track-cjk`、不用 uppercase、行高 1.5–1.6）**继续保留** ——
因为中文数据/样品名仍会出现在界面里。

## 5. 怎么查

> 三个体检器（**裸字号/裸色**、**三主题对比度 WCAG AA**、**无头浏览器量尺寸+截图+抓控制台报错**）
> 属内部工作区工具，**不在本仓库**；本文只固化它们判定的**规则本身**（字号 6 档 / 颜色走变量 / 对比度达 AA）。

改完 UI 必须跑上面第三条——**别只改文件不看效果**。

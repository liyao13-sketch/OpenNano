# OpenNano 品牌与标记规范

> 2026-09-13 建立（工具线 · the assistant）。矢量的**唯一真源**在 `web/public/brand/`，本文说明怎么用、别怎么用。

## 1. 标记（mark）

一个 **N**，由**三段工序**组成：第一段（左竖笔）点着强调色，后两段走文字色。

| 语义 | 说明 |
|---|---|
| **N** | Nano —— 名字本身 |
| **三段** | 一段工艺由若干**步骤**组成（也是画布上"节点 + 连线"的抽象） |
| **只有一段着色** | 「强调色唯一且克制」——整枚标记只有一个色相参与，其余靠明暗 |

- 源文件：`brand/logo-mark.svg`（着色段写死强调色，另两段 `currentColor` ⇒ **内联进页面自动跟主题**）
- 最小尺寸 **14px**；四周留白 ≥ **4px**（= 32 视框里的 4，约标记高度的 1/8）
- 深底用 `#6d78dc`，浅底用 `#4f46e5`（就是三主题里的强调色 token，不另造色）

## 2. 横版锁定（lockup）

`标记 + 字标`，间距 **7px**（≈ 标记高度的 2/5，别再挤）。整体最小高度 **24px**。

| 文件 | 用在哪 |
|---|---|
| `brand/logo-lockup-light.svg` | **浅色底**（白/浅灰）——字标 `#0f172a` |
| `brand/logo-lockup-dark.svg` | **深色底**（近黑/深灰）——字标 `#f7f8f8` |

字标用**系统 UI 字体栈**（`Inter → -apple-system → PingFang SC → …`），与产品界面同一套 —— 不引第三方字体，免联网依赖。产品界面里的字标是**真文本**（不是图片），所以永远清晰、可选中。

## 3. 页签 / 应用图标

`web/public/favicon.svg` = 标记坐在深色圆角砖上（砖色 = 产品面板色 `#0e0f11`）。
用深砖的原因：浏览器页签底色有深有浅，标记两段是浅色，坐砖上才**在任何主题下都看得见**。

## 4. 配色（与 UI 同一套 token，别另起一套）

| 用途 | 深色主题 | 浅色主题 | 高对比主题 |
|---|---|---|---|
| 标记着色段 / 强调色 | `#6d78dc` | `#4f46e5` | `#79bcff` |
| 标记另两段 / 字标 | `#f7f8f8` | `#0f172a` | `#ffffff` |

全部取自 `web/src/styles.css` 的 `--accent-text` / `--text`；改主题时 logo 自动跟（三主题一致性由 `工具/配色体检.py` 机器校验对比度）。

## 5. 别这么做

- ❌ 别改比例、别拉伸（等比缩放；正方形标记不许压成扁的）
- ❌ 别给标记加描边、阴影、渐变、外发光（"质感"靠留白和字重，不靠特效）
- ❌ 别把着色段换成别的颜色或第二个色相（唯一强调色是这套设计的支点）
- ❌ 别在标记外面再套一层圆角砖（除页签图标那种必须的场合）
- ❌ 别把字标改成全大写 `OPENNANO` 或拆行

## 6. 复现 / 校验

```bash
# 把四个矢量渲染成一张对照图（浅底/深底/页签 16-64px/最小尺寸）
node /path/to/logo_preview.cjs     # 或直接开 web/public/brand/*.svg 看
```

改完标记请顺手跑一次 UI 实测（`工具/UI截图.cjs`）——顶栏是产品第一屏，别只改文件不看效果。
